
# TravelSafe

TravelSafe is a hybrid Algorand DApp for journey condition verification.

## Planned Features
- Destination search
- Weather conditions
- Daylight conditions
- Travel advisory data
- Combined journey summary
- Algorand blockchain recording
- Code quality and version control

## Tech Stack
- React
- Vite
- TypeScript
- Node.js
- Express
- Algorand Localnet
- GitHub
- ESLint
- Prettier
